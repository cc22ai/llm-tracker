# LLM Release Tracker

A live tracker of newly-released AI foundation models (text/code/chat LLMs) across 12 vendors:
Anthropic, OpenAI, xAI, Google, Meta, Z.ai, DeepSeek, Moonshot AI, MiniMax, Tencent, Alibaba, and Xiaomi Mimo.

Tracks release date, tier, context length, parameters, open-weights status, and per-1M-token pricing (USD + RMB).

- Live site: https://cc22ai.github.io/llm-tracker/
- Updated by an automated pipeline that merges `data/new_entries.json` into `data/models.json` and rebuilds the HTML.

Data is sourced from official vendor news/pricing/docs pages and reputable aggregators.
